# Virtuelna pametna sigurnosna kamera

IoT prototip: detekcija pokreta (PIR), reakcija ESP32 (LED, buzzer, servo),
komunikacija preko MQTT-a i prepoznavanje objekata u veb-pregledaču (COCO-SSD).

Wokwi simulator
[https://wokwi.com/projects/481344659910891521]
Web kontrole
[https://yhozi.github.io/iot-security-camera/]

## Struktura
- `firmware/` – ESP32 program i Wokwi šema
- `docs/` – šema i dokumentacija
